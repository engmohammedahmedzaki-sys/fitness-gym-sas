# Fitness Gym SaaS

Arabic RTL gym and sports academy management SaaS by Mohamed Zaki / Panda Plus.

## Stack

- React
- Vite
- Tailwind CSS
- Framer Motion
- Capacitor-ready frontend architecture

## Main Areas

- Public landing page and signup flow
- Login and protected dashboard
- Members, finance, basic data, reports
- Payment gateway settings for Paymob and Fawaterk
- WhatsApp card/PDF workflow prototype
- Multi-tenant master console foundation
